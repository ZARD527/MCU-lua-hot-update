# Changelog

## 0.1.0 - 2026-09-29

- Added STM32F411 Lua 5.4.8 MCU integration.
- Added Flash A/B Lua script storage and CRC32 validation.
- Added CRC16-protected UART update packets and binary acknowledgements.
- Added packet sequence checks, retransmission handling and receive timeouts.
- Added coroutine-based Lua execution and non-blocking `delay_ms()`.
- Added PyQt5 serial updater and protocol regression tests.
- Added release-oriented repository structure, security policy and third-party notices.
